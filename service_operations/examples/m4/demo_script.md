# Service Operations｜5 分钟演示讲述稿

**开场（30 秒）**：这是本地演示系统。所有工单、设备、站点和 SLA 都是按固定种子合成的；厂商手册是真实公开 PDF，自编流程便签明确标为演示。目标是把运营指标和适用版本的文档证据放在一个查询结果里。

**1. 准备数据（45 秒）**：进入「数据维护」，点击「导入 M0 合成样本」和「下载并建立演示手册索引」。顶部显示活动快照 ID、18 台设备、670 条工单、4 条 SLA 策略；下方显示两份官方手册和便签 v1/v2 的索引状态。已准备好数据时，两项操作是幂等的。

**2. 从趋势到工单（75 秒）**：进入「指标与趋势」，选 `TAZ_PRO`、`NOZZLE_WIPE`，区间设为 2026-06-01 至 2026-09-01。三项卡片分别来自预定义 SQL。趋势指标选「30 天重复故障率」，按故障分类分组，点选 2026-08 的 `NOZZLE_WIPE` 柱形。展示 `8/9` 和下方 9 条入选工单；指出 `metric_outcome` 与 `prior_work_order_id`。说明分母由定义决定，不由图表视觉猜测。

**3. 联合提问（75 秒）**：进入「联合提问」，保留默认问题并查询。指出本期 `25/33=75.76%`、等长前期 `11/21=52.38%`、变化 `+23.38` 个百分点，查看快照 ID 和工单 ID。指出文档证据中自编记录流程 v2 的第 1 页与厂商排障手册的第 83 页；两份材料承担不同角色。这个“上升”是合成规则注入的演示现象，不是实际设备可靠性结论。

**4. 错误批次（45 秒）**：返回「数据维护」，点击「导入故意错误批次」。查看 6 条质量问题和拒收规则；活动快照、670 条有效工单不变。说明导入按完整快照事务切换，拒收不会污染当前指标。

**5. 历史版本（30 秒）**：把联合提问切换成手册模式，问题改为 `NOZZLE_WIPE 服务记录流程`，查询时点填 `2026-06-01T00:00:00+08:00`。展示 v1；改回 2026-09-28 则是 v2。版本先于检索 Top-K 选定，旧版再相似也不会误入当前答案。

**收尾（15 秒）**：目前结果是确定性 SQL 和有出处的短摘录。还需 M5 的独立任务集、保留集和人工核引，才能讨论效果；不把合成样本指标当成企业上线收益。
